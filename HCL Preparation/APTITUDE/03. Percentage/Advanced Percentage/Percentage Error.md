# Percentage Error

## 1. Core Concept

> [!summary]
> **Percentage error** measures how far an approximate, measured, estimated, or incorrect value is from the true/actual value, expressed as a percentage.

The basic formula is:

$$
\boxed{
\text{Percentage Error}
=
\frac{|\text{Approximate Value}-\text{True Value}|}
{\text{True Value}}
\times100
}
$$

---

# 2. Important Terms

| Term | Meaning |
|---|---|
| True Value | Correct/actual value |
| Approximate Value | Estimated or measured value |
| Error | Difference between approximate and true value |
| Absolute Error | Magnitude of the difference |
| Percentage Error | Error expressed as percentage of true value |

---

# 3. Absolute Error

If:

True value:

$$
100
$$

Approximate value:

$$
95
$$

Absolute error:

$$
|95-100|
=
\boxed{5}
$$

---

# 4. Percentage Error

Using the same example:

$$
\frac{|95-100|}{100}\times100
$$

$$
=\boxed{5\%}
$$

---

# 5. Main Formula

If:

- True value = `T`
- Approximate value = `A`

then:

$$
\boxed{
\text{Percentage Error}
=
\frac{|A-T|}{T}\times100
}
$$

> [!important]
> **The denominator is the true/actual value.**

---

# 9. Underestimation

If the estimated value is less than the true value:

$$
A<T
$$

then:

$$
\boxed{
\text{Underestimation}
=
\frac{T-A}{T}\times100
}
$$

Example:

True = `500`

Estimate = `450`

$$
\frac{500-450}{500}\times100
=
\boxed{10\%}
$$

---

# 10. Overestimation

If:

$$
A>T
$$

$$
\boxed{
\text{Overestimation}
=
\frac{A-T}{T}\times100
}
$$

Example:

True = `500`

Estimate = `550`

$$
\frac{550-500}{500}\times100

\boxed{10\%}
$$

---

# 11. Error Can Be Positive or Negative

Signed error:

$$
\boxed{
\text{Error}=A-T
}
$$

If:

$$
A>T
$$

error is positive.

If:

$$
A<T
$$

error is negative.

But percentage error usually uses absolute value:

$$
\boxed{
\frac{|A-T|}{T}\times100
}
$$

Therefore percentage error is normally reported as a positive quantity.

---

$$

=
-5
$$

$$
5

$$

\boxed{2\%}
$$

# 13. Finding Error From Percentage Error

True value:

$$
800
$$

Percentage error:

`5%`

Error:

$$
800\times\frac5{100}
$$

$$
=\boxed{40}
$$

Therefore approximate value could be:

### Underestimate

$$
800-40
=
\boxed{760}
$$

### Overestimate

$$
800+40
=
\boxed{840}
$$

# 14. Finding True Value

Suppose an approximate value is `950`, and it is `5%` less than the true value.

Then:

$$
950=95\%\text{ of True Value}
$$

Therefore:

$$
\text{True Value}
=
\frac{950}{0.95}
$$

$$
=\boxed{1000}
$$

---

# 15. True Value From Overestimate

An estimate of `1,050` is `5%` greater than the true value.

Therefore:

$$
1050=105\%\text{ of True Value}
$$

$$
\text{True Value}
=
\frac{1050}{1.05}
$$

$$
=\boxed{1000}
$$

# 16. Error Bound

Sometimes the question says:

> The measurement has an error of at most `2%`.

This means:

$$
\boxed{
|\text{Measured}-\text{True}|
\leq
2\%\text{ of True}
}
$$

If true value is approximately `500`:

Maximum error:

$$
500\times0.02
=
10
$$

So approximate value lies roughly around:

$$
490\text{ to }510
$$

# 22. Percentage Error vs Percentage Difference

> [!important]
> These are **not always the same concept**.

### Percentage Error

Compares an approximate value with a known true value:

$$
\boxed{
\frac{|A-T|}{T}\times100
}
$$

### Percentage Difference

Usually compares two values when neither is necessarily treated as the true value:

$$
\boxed{
\frac{|A-B|}
{(A+B)/2}
\times100
}
$$

The denominator is different.

---

# 23. Example — Error

True:

$$
100
$$

Approximate:

$$
90
$$

Percentage error:

$$
\frac{10}{100}\times100
=
\boxed{10\%}
$$

---

# 24. Example — Percentage Difference

Values:

$$
100,\quad90
$$

Difference:

$$
10
$$

Average:

$$
\frac{100+90}{2}
=
95
$$

Percentage difference:

$$
\frac{10}{95}\times100
$$

$$
=\boxed{10.53\%}
$$

Notice:

$$
10\%\ne10.53\%
$$

# 25. Error in a Calculated Quantity

If a quantity depends on another measured quantity, the percentage error may propagate.

For simple aptitude questions, the most important rules are:

### Multiplication

If:

$$
Z=XY
$$

then approximately:

$$
\boxed{
\%\text{ error in }Z
\approx
\%\text{ error in }X
+
\%\text{ error in }Y
}
$$

---

# 26. Example — Multiplication Error

Suppose:

- X has `2%` error
- Y has `3%` error

and:

$$
Z=XY
$$

Approximate percentage error:

$$
2+3
=
\boxed{5\%}
$$

---

# 27. Division Error

If:

$$
Z=\frac XY
$$

then approximately:

$$
\boxed{
\%\text{ error in }Z
\approx
\%\text{ error in }X
+
\%\text{ error in }Y
}
$$

for maximum-error style aptitude questions.

---

# 28. Example — Division

X has `2%` error.

Y has `4%` error.

$$

\boxed{6\%}

# 41. Addition/Subtraction Error

If:

$$

$$
\boxed{

> [!warning]
> Do not blindly add percentage errors for addition/subtraction. Add **absolute errors** first.

# 58. General Error Rule

For:

$$
Y=
\frac{
A^pB^q
}{
C^rD^s
}
$$

approximate percentage error:

$$
\boxed{
|p|E_A+|q|E_B+|r|E_C+|s|E_D
}
$$

where each `E` is the percentage error in that variable.

---

# 59. Example

$$
Y=\frac{A^2B^3}{C}
$$

Errors:

- A = `1%`
- B = `2%`
- C = `4%`

Approximate error:

$$
2(1)+3(2)+4
$$

$$
=2+6+4
$$

$$
\boxed{12\%}
$$

# 60. Common Mistakes

> [!warning] Avoid These

### Mistake 1

Using approximate value in the denominator.

Usually:

$$
\boxed{\text{True value}}
$$

is the denominator.

### Mistake 2

Confusing error with percentage error.

Error has units.

Percentage error does not.

### Mistake 3

Confusing percentage error with percentage difference.

### Mistake 4

Adding percentage errors for addition/subtraction.

For those, use absolute errors first.

### Mistake 5

Forgetting powers.

If:

$$
Y=X^3
$$

the percentage error is approximately:

$$
3\times E_X
$$

not just `E_X`.

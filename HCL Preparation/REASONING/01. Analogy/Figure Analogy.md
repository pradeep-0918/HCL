# Figure Analogy

## 1. Core Concept

> [!summary]
> **Figure Analogy** identifies the visual transformation between two figures and applies the same transformation to another figure.

Basic pattern:

$$
A:B::C:D
$$

Here, the figures may be related through:

- Rotation
- Reflection
- Movement
- Enlargement or reduction
- Addition or removal of elements
- Change in shading
- Change in position
- Change in direction
- Change in number of elements
- Combination of multiple transformations

The key skill is:

> **Observe what changes from Figure A to Figure B, then repeat the same change on Figure C.**

---

# 2. Basic Meaning

Figure analogy is a **non-verbal reasoning** topic.

Instead of words or numbers, the question uses shapes, lines, arrows, dots, symbols, or geometric figures.

### Standard Structure

$$
Figure\ A\rightarrow Figure\ B
$$

Then:

$$
Figure\ C\rightarrow ?
$$

The missing figure must follow the **same visual relationship**.

### Example

Suppose Figure A contains an arrow pointing:

$$
\uparrow
$$

and Figure B contains:

$$
\rightarrow
$$

The arrow has rotated $90^\circ$ clockwise.

If Figure C contains:

$$
\leftarrow
$$

then rotate it $90^\circ$ clockwise:

$$
\leftarrow\rightarrow\downarrow
$$

Therefore:

$$
\boxed{\downarrow}
$$

---

# 3. Main Formula

There is no single numerical formula.

The general rule is:

$$
\boxed{Transformation(A)=B}
$$

Therefore:

$$
\boxed{Transformation(C)=D}
$$

Common transformations:

| Transformation | Meaning |
|---|---|
| Rotation | Figure turns around a point |
| Reflection | Figure flips across an axis |
| Translation | Figure moves position |
| Enlargement | Figure becomes larger |
| Reduction | Figure becomes smaller |
| Addition | New element is added |
| Removal | Element is deleted |
| Shading | Filled/unfilled state changes |
| Direction Change | Arrow or symbol changes direction |
| Position Change | Element moves within the figure |
| Element Count | Number of components changes |

---

# 4. Important Properties

1. The overall transformation must be the same.
2. Compare the figures systematically.
3. Check orientation first.
4. Check position second.
5. Check the number of elements third.
6. Check shading and size next.
7. For arrows, track their direction carefully.
8. For polygons, count sides and vertices.
9. For dots and lines, count their number and position.
10. Do not assume a rotation when reflection explains the transformation better.
11. Multiple transformations may occur together.
12. Use the simplest transformation that explains all changes.

### Important Observation Order

Use:

$$
\boxed{\text{Shape}\rightarrow\text{Direction}\rightarrow\text{Position}\rightarrow\text{Count}\rightarrow\text{Shading}}
$$

This makes visual questions faster.

# 5. Basic Examples

## Example 1 — Rotation

### Question

Figure A contains an arrow pointing upward.

Figure B contains the same arrow pointing right.

Figure C contains an arrow pointing downward.

What should Figure D contain?

### Pattern Recognition

A → B:

$$
\uparrow\rightarrow
$$

This is a:

$$
90^\circ\ clockwise\ rotation
$$

Apply the same transformation:

$$
\downarrow\rightarrow\leftarrow
$$

### Answer

$$
\boxed{\leftarrow}
$$

---

## Example 2 — Reflection

### Question

Figure A contains a shape on the left side.

Figure B contains the same shape on the right side.

Figure C contains a shape on the left side.

What is Figure D?

### Pattern Recognition

The transformation is a **horizontal reflection**.

Therefore the shape moves:

$$
Left\rightarrow Right
$$

### Answer

$$
\boxed{\text{Same shape on the right}}
$$

---

## Example 3 — Addition of Element

### Question

Figure A contains one dot.

Figure B contains two dots.

Figure C contains three dots.

What should Figure D contain?

### Pattern Recognition

The transformation is:

$$
+1\ dot
$$

Apply to Figure C:

$$
3+1=4
$$

### Answer

$$
\boxed{4\ dots}
$$

---

## Example 4 — Removal of Element

### Question

Figure A contains four lines.

Figure B contains three lines.

Figure C contains five lines.

What should Figure D contain?

### Pattern Recognition

One line is removed:

$$
-1
$$

Therefore:

$$
5-1=4
$$

### Answer

$$
\boxed{4\ lines}
$$

---

# 6. Medium Examples

## Example 5 — Rotation + Position

### Question

Figure A contains a triangle pointing upward with a dot above it.

Figure B contains the same triangle pointing right with the dot on its right.

Figure C contains a triangle pointing downward with a dot below it.

Find Figure D.

### Pattern Recognition

From A → B:

- Triangle rotates $90^\circ$ clockwise.
- Dot rotates with the figure.

Therefore:

$$
\downarrow\rightarrow\leftarrow
$$

The dot moves from below to the left.

### Answer

$$
\boxed{\text{Left-pointing triangle with dot on the left}}
$$

---

## Example 6 — Shading Transformation

### Question

Figure A contains an unshaded circle.

Figure B contains a shaded circle.

Figure C contains an unshaded square.

What should Figure D contain?

### Pattern Recognition

The transformation is:

$$
Unshaded\rightarrow Shaded
$$

Therefore the square becomes shaded.

### Answer

$$
\boxed{\text{Shaded square}}
$$

---

## Example 7 — Enlargement

### Question

Figure A contains a small triangle.

Figure B contains a large triangle.

Figure C contains a small circle.

What should Figure D contain?

### Pattern Recognition

The shape stays the same while its size increases.

Therefore:

$$
Small\ Circle\rightarrow Large\ Circle
$$

### Answer

$$
\boxed{\text{Large circle}}
$$

---

# 7. Advanced Examples

## Example 8 — Rotation by 180°

### Question

Figure A has an arrow pointing upward.

Figure B has an arrow pointing downward.

Figure C has an arrow pointing left.

What should Figure D contain?

### Pattern Recognition

A → B:

$$
\uparrow\rightarrow\downarrow
$$

This is:

$$
180^\circ
$$

rotation.

Apply to C:

$$
\leftarrow\rightarrow
$$

### Answer

$$
\boxed{\rightarrow}
$$

---

## Example 9 — Reflection + Shading

### Question

Figure A has a shaded triangle on the left.

Figure B has an unshaded triangle on the right.

Figure C has a shaded square on the left.

What should Figure D contain?

### Pattern Recognition

Two transformations occur:

1. Left → Right
2. Shaded → Unshaded

Apply both:

$$
Shaded\ Left\ Square
$$

becomes:

$$
Unshaded\ Right\ Square
$$

### Answer

$$
\boxed{\text{Unshaded square on the right}}
$$

---

## Example 10 — Element Movement

### Question

Figure A contains a circle with a dot at the top.

Figure B contains a circle with the dot at the bottom.

Figure C contains a square with a dot at the top.

What should Figure D contain?

### Pattern Recognition

The outer shape remains unchanged.

The dot moves:

$$
Top\rightarrow Bottom
$$

Therefore:

$$
Square+\text{dot at bottom}
$$

### Answer

$$
\boxed{\text{Square with dot at the bottom}}
$$

---

# 8. Combination Transformations

Some difficult questions use more than one transformation.

## Example 11

### Question

Figure A contains:

- A triangle
- One shaded dot
- Arrow pointing upward

Figure B contains:

- Same triangle
- Unshaded dot
- Arrow pointing right

Figure C contains:

- A square
- One shaded dot
- Arrow pointing upward

Find Figure D.

### Pattern Recognition

A → B has:

1. Arrow rotates $90^\circ$ clockwise.
2. Dot changes shaded → unshaded.
3. Triangle remains unchanged.

Apply to C:

- Square remains square.
- Dot becomes unshaded.
- Arrow points right.

### Answer

$$
\boxed{\text{Square + unshaded dot + right-pointing arrow}}
$$

# 9. Recognition Tricks

## Pattern 1 — Rotation

> [!important]
> If the shape remains the same but its orientation changes, think **Rotation**.

Check:

$$
90^\circ,\ 180^\circ,\ 270^\circ
$$

Common rotations:

| Rotation | Direction |
|---|---|
| $90^\circ$ clockwise | Quarter turn |
| $180^\circ$ | Half turn |
| $270^\circ$ clockwise | Same as $90^\circ$ anticlockwise |

---

## Pattern 2 — Reflection

> [!important]
> If the figure appears flipped across a line, think **Reflection**.

Check:

- Left ↔ Right
- Top ↔ Bottom

---

## Pattern 3 — Element Addition

> [!important]
> If the same figure gains an element, think **Addition**.

Example:

$$
2\ dots\rightarrow3\ dots
$$

---

## Pattern 4 — Element Removal

> [!important]
> If an element disappears, think **Removal**.

Example:

$$
4\ lines\rightarrow3\ lines
$$

---

## Pattern 5 — Shading

> [!important]
> If only filled/unfilled status changes, think **Shading Transformation**.

Example:

$$
White\rightarrow Black
$$

---

## Pattern 6 — Size

> [!important]
> If the shape stays the same but becomes larger or smaller, think **Size Transformation**.

---

## Pattern 7 — Position

> [!important]
> If the element moves while its shape remains unchanged, think **Position Change**.

Example:

$$
Top\rightarrow Bottom
$$

---

## Pattern 8 — Multiple Transformations

> [!important]
> If more than one property changes, check whether the same combination is applied to both pairs.

Example:

$$
Rotation + Shading
$$

or:

$$
Reflection + Position
$$

---

# 10. Shortcuts

> [!tip]
> **Shortcut 1 — Ignore the shape initially**

First check:

- Direction
- Position
- Number of elements
- Shading

This can reveal the transformation quickly.

---

> [!tip]
> **Shortcut 2 — Track one unique element**

If a figure contains several shapes, choose one distinctive feature.

For example:

> "Where did the black dot go?"

Tracking one element often reveals the entire transformation.

---

> [!tip]
> **Shortcut 3 — Check rotation before complex rules**

If everything appears identical except orientation, test:

$$
90^\circ,\ 180^\circ,\ 270^\circ
$$

---

> [!tip]
> **Shortcut 4 — Count elements**

For dots, lines, triangles, circles, etc., quickly compare:

$$
Count(A)\rightarrow Count(B)
$$

If the count changes consistently, use that pattern.

---

> [!tip]
> **Shortcut 5 — Separate shape from position**

Ask two questions:

1. Did the shape change?
2. Did the position change?

This prevents confusing a movement with a transformation of the object itself.

# 12. Common Mistakes

> [!warning] Avoid These

### Mistake 1 — Confusing rotation with reflection

A rotation turns the entire figure.

A reflection flips the figure.

For example:

$$
\uparrow\xrightarrow{90^\circ}\rightarrow
$$

is rotation.

But a mirror operation changes left/right orientation.

---

### Mistake 2 — Looking only at the outer shape

The outer shape may remain unchanged while:

- dots move
- arrows rotate
- shading changes
- lines are added

Always inspect the **entire figure**.

---

### Mistake 3 — Ignoring small elements

A single dot or short line may be the main clue.

Always count and track small components.

---

### Mistake 4 — Assuming only one transformation

Some questions deliberately combine:

$$
Rotation + Shading
$$

or:

$$
Movement + Addition
$$

Check every visible change.

---

### Mistake 5 — Overcomplicating a simple transformation

If a $90^\circ$ rotation explains everything, do not invent a complicated positional rule.

---

### Mistake 6 — Not checking all parts

If the triangle rotates but the dot also moves, the transformation is not just:

> "Rotate the triangle."

The dot's transformation must also match.

# 13. Formula Sheet

$$
\boxed{90^\circ,\ 180^\circ,\ 270^\circ}
$$

## Horizontal Reflection

$$
\boxed{Left\leftrightarrow Right}
$$

## Vertical Reflection

$$
\boxed{Top\leftrightarrow Bottom}
$$

$$
\boxed{N'=N+k}
$$

## Element Removal

$$
\boxed{N'=N-k}
$$

## General Transformation

$$
\boxed{T(A)=B\Rightarrow T(C)=D}
$$

## Main Observation Order

$$
\boxed{Shape\rightarrow Direction\rightarrow Position\rightarrow Count\rightarrow Shading}
$$

# 14. Quick Revision

> [!summary] One-Minute Revision

### Figure Analogy

$$
A:B::C:D
$$

Find what changes from Figure A to Figure B.

Apply exactly the same transformation to Figure C.

### Check First

1. Rotation
2. Reflection
3. Position
4. Direction
5. Number of elements
6. Shading
7. Size
8. Shape
9. Multiple transformations

### Most Important Questions

- Is it rotated?
- Is it reflected?
- Did an element move?
- Was something added?
- Was something removed?
- Did shading change?
- Did the size change?
- Did multiple changes happen together?

### Golden Memory Trick

**"Track the change, not the shape."**

# One-Line Recognition

**When you see a figure analogy, compare every visible property from A to B and reproduce the same transformation from C to the missing figure.**

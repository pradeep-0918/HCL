# Word Analogy

## 1. Core Concept

> [!summary]
> **Word Analogy** identifies the relationship between two words and applies the **same relationship** to another pair of words.

Basic pattern:

$$
A:B::C:D
$$

Read as:

**A is related to B in the same way that C is related to D.**

The main skill is not memorizing relationships. It is **recognizing the relationship quickly**.

### Intuition

Think:

> "What happens to A to become B?"

Then apply exactly the same idea to C.

Example:

**Bird : Nest :: Lion : ?**

Bird lives in a **Nest**.

Lion lives in a **Den**.

Therefore:

$$
\boxed{\text{Den}}
$$

---

# 2. Basic Meaning

An analogy question gives a relationship between two words and asks you to find the word that has the **same relationship** with another word.

### Standard Form

| Part | Meaning |
|---|---|
| A | First word |
| B | Related word |
| C | New word |
| D | Missing word |

$$
A:B::C:D
$$

The relationship:

$$
A\rightarrow B
$$

must be the same as:

$$
C\rightarrow D
$$

### Example

**Doctor : Hospital :: Teacher : ?**

Doctor works in a hospital.

Teacher works in a school.

Therefore:

$$
\boxed{\text{School}}
$$

---

# 3. Main Formula

There is no numerical formula for word analogy.

The main rule is:

$$
\boxed{\text{Relationship}(A,B)=\text{Relationship}(C,D)}
$$

### Common Relationship Types

| Relationship | Example |
|---|---|
| Profession → Workplace | Doctor : Hospital |
| Animal → Home | Lion : Den |
| Animal → Young One | Cow : Calf |
| Object → Function | Knife : Cut |
| Person → Tool | Carpenter : Hammer |
| Object → Material | Chair : Wood |
| Synonym | Big : Large |
| Antonym | Hot : Cold |
| Part → Whole | Wheel : Car |
| Whole → Part | Car : Wheel |
| Cause → Effect | Exercise : Fitness |
| Country → Capital | India : New Delhi |
| Country → Currency | Japan : Yen |
| Person → Invention | Edison : Bulb |
| Worker → Product | Farmer : Crops |
| Animal → Sound | Dog : Bark |
| Animal → Group | Lions : Pride |
| Object → Location | Books : Library |
| Degree/Intensity | Warm : Hot |

---

# 4. Important Properties

1. The relationship must be **logical and specific**.
2. The order of words matters.
3. Do not select an answer merely because the words are associated.
4. The relationship between the first pair must match the second pair.
5. Prefer the **most direct relationship**.
6. Check whether the relationship is:
   - functional
   - categorical
   - positional
   - oppositional
   - sequential
   - causal
   - quantitative
7. Avoid relationships that require unnecessary assumptions.
8. In multiple-choice questions, eliminate options using the exact relationship.

### Direction Matters

Consider:

**Book : Page**

This means:

> Page is a part of Book.

But:

**Page : Book**

means:

> Book is the whole containing Page.

So:

$$
\boxed{\text{Order matters}}
$$

# 8. Shortcuts

> [!tip]
> **Shortcut 1 — Ask "What is the exact connection?"**

Do not think about the words individually.

Immediately ask:

> "How is A connected to B?"

Then apply that relationship to C.

---

> [!tip]
> **Shortcut 2 — Convert the relationship into a sentence**

Example:

**Bird : Nest**

Convert to:

> "A bird lives in a nest."

Now:

**Lion : ?**

> "A lion lives in a ___."

Answer becomes obvious:

$$
\boxed{\text{Den}}
$$

---

> [!tip]
> **Shortcut 3 — Identify the relationship category first**

Before looking deeply at options, classify the pair:

$$
\text{Profession → Workplace}
$$

$$
\text{Animal → Young One}
$$

$$
\text{Object → Function}
$$

$$
\text{Part → Whole}
$$

This makes elimination much faster.

---

> [!tip]
> **Shortcut 4 — Check direction**

For:

**Teacher : School**

Think:

> Teacher works in School.

Do not reverse it to:

> School works in Teacher.

The direction must remain unchanged.

---

> [!tip]
> **Shortcut 5 — Use elimination**

If the first pair represents:

$$
\text{Animal → Home}
$$

remove options representing:

- animal sound
- animal food
- animal young one

Keep only options representing an **animal's home**.

# 9. Recognition Tricks

## Pattern 1 — Profession → Workplace

> [!important]
> If the question says **Doctor : Hospital**, think **Profession → Workplace**.

### Formula

$$
Profession\rightarrow Workplace
$$

### Example

**Teacher : School :: Doctor : ?**

Answer:

$$
\boxed{\text{Hospital}}
$$

---

## Pattern 2 — Animal → Home

> [!important]
> If the question gives **Lion : Den**, think **Animal → Home**.

### Formula

$$
Animal\rightarrow Home
$$

Examples:

- Lion → Den
- Horse → Stable
- Dog → Kennel
- Bird → Nest

---

## Pattern 3 — Animal → Young One

> [!important]
> If the question gives **Cow : Calf**, think **Animal → Young One**.

Examples:

- Cow → Calf
- Dog → Puppy
- Cat → Kitten
- Horse → Foal

---

## Pattern 4 — Object → Function

> [!important]
> If the question gives **Pen : Write**, think **Object → Function**.

### Formula

$$
Object\rightarrow Function
$$

Examples:

- Knife → Cut
- Pen → Write
- Camera → Photograph
- Clock → Show time

---

## Pattern 5 — Person → Tool

> [!important]
> If the question gives **Carpenter : Saw**, think **Profession → Tool**.

Examples:

- Carpenter → Saw
- Barber → Scissors
- Doctor → Stethoscope
- Farmer → Plough

---

## Pattern 6 — Part → Whole

> [!important]
> If the question says **Wheel : Car**, think **Part → Whole**.

Examples:

- Finger → Hand
- Page → Book
- Engine → Car
- Leaf → Tree

---

## Pattern 7 — Whole → Part

> [!important]
> If the question says **Car : Wheel**, think **Whole → Part**.

This is the reverse of Part → Whole.

---

## Pattern 8 — Synonym

> [!important]
> If the words have the same or nearly the same meaning, think **Synonym**.

Example:

**Happy : Joyful :: Fast : ?**

Answer:

$$
\boxed{\text{Rapid}}
$$

---

## Pattern 9 — Antonym

> [!important]
> If the words have opposite meanings, think **Antonym**.

Example:

**High : Low :: Rich : ?**

Answer:

$$
\boxed{\text{Poor}}
$$

---

## Pattern 10 — Country → Capital

> [!important]
> If the question gives a country and a city, check whether the city is its capital.

Example:

**India : New Delhi :: Japan : ?**

Answer:

$$
\boxed{\text{Tokyo}}
$$

---

## Pattern 11 — Country → Currency

> [!important]
> If the first word is a country and the second is money used there, think **Country → Currency**.

Example:

**Japan : Yen :: India : ?**

Answer:

$$
\boxed{\text{Rupee}}
$$

---

## Pattern 12 — Cause → Effect

> [!important]
> If the first word produces or causes the second, think **Cause → Effect**.

Example:

**Rain : Flood :: Virus : ?**

Possible relationship:

$$
Cause\rightarrow Effect
$$

The answer depends on the exact options and intended relationship.

# 11. Common Mistakes

> [!warning] Avoid These

### Mistake 1 — Choosing a loosely associated word

Example:

**Doctor : Hospital**

Choosing "Medicine" because doctors use medicine is weaker than "Hospital" because the relationship is **Profession → Workplace**.

### Correct Approach

Find the **exact relationship**, not merely an association.

---

### Mistake 2 — Reversing the relationship

**Book : Page**

means:

> Page is part of Book.

It does not mean:

> Book is part of Page.

Always preserve direction.

---

### Mistake 3 — Ignoring the relationship type

**Pen : Write**

is:

$$
Object\rightarrow Function
$$

It is not:

$$
Object\rightarrow Material
$$

---

### Mistake 4 — Overthinking simple analogies

If the relationship is obvious, do not search for complicated hidden logic.

Example:

**Dog : Puppy**

Simply means:

$$
Animal\rightarrow Young\ One
$$

---

### Mistake 5 — Using general knowledge incorrectly

Some words can have multiple relationships.

Example:

**Doctor : Hospital**

Possible associations include:

- doctor works in hospital
- doctor treats patients
- hospital contains doctors

Choose the relationship that best fits the answer options.

---

### Mistake 6 — Ignoring word order

**Tool : User** and **User : Tool** are different relationships.

Always preserve:

$$
A\rightarrow B
$$

and apply the same direction to:

$$
C\rightarrow D
$$

# 13. Quick Revision

> [!summary] One-Minute Revision

### Word Analogy

$$
A:B::C:D
$$

means:

> A is related to B in the same way C is related to D.

### Fast Method

1. Read A and B.
2. Identify the exact relationship.
3. Convert it into a simple sentence.
4. Apply the same relationship to C.
5. Check the options.
6. Verify direction.

### Most Important Relationships

- Profession → Workplace
- Profession → Tool
- Animal → Home
- Animal → Young One
- Object → Function
- Part → Whole
- Whole → Part
- Cause → Effect
- Country → Capital
- Country → Currency
- Synonym
- Antonym

### Golden Rule

$$
\boxed{\text{Do not find a related word; find the same relationship.}}
$$

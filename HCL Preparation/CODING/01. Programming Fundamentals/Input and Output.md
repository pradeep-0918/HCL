# Input and Output

## 1. Core Concept

> [!summary]
> **Input** is the data given to a program. **Output** is the result produced by the program.

The basic flow of almost every coding problem is:

$$
\text{Input} \rightarrow \text{Processing} \rightarrow \text{Output}
$$

Example:

~~~text
Input:
10 20

Processing:
10 + 20

Output:
30
~~~

In competitive programming and placement coding questions, understanding input format correctly is extremely important.

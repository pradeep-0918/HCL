# Subject Object

## 1. Core Concept

> [!summary]
> The **Subject** is the person, thing, or idea that performs the action or is being described. The **Object** is the person, thing, or idea that receives the action.
>
> **Subject → performs the action**
>
> **Object → receives the action**

### Basic Structure

$$
\boxed{\text{Subject} + \text{Verb} + \text{Object}}
$$

Example:

> Ravi kicked the ball.

- Subject = Ravi
- Verb = kicked
- Object = the ball

### Core Intuition

Ask two questions:

1. **Who/What performed the action?** → Subject
2. **Who/What received the action?** → Object

---

# 2. Basic Meaning

## Subject

The subject usually performs the action.

Example:

> Priya opened the door.

Who opened?

> Priya

Therefore:

$$
\boxed{\text{Subject = Priya}}
$$

---

## Object

The object receives the action.

Example:

> Priya opened the door.

What did Priya open?

> the door

Therefore:

$$
\boxed{\text{Object = the door}}
$$

---

# 3. Main Formula

The most common sentence pattern is:

$$
\boxed{S + V + O}
$$

Where:

- $S$ = Subject
- $V$ = Verb
- $O$ = Object

Example:

> The student solved the problem.

$$
\boxed{\text{The student} + \text{solved} + \text{the problem}}
$$

---

# 4. Subject vs Object

| Feature | Subject | Object |
|---|---|---|
| Main role | Performs/experiences action | Receives action |
| Usually appears | Before verb | After verb |
| Main question | Who/What? | Whom/What? |
| Controls agreement | Yes | No |
| Example | Ravi | the ball |
| Sentence | Ravi kicked the ball | Ravi kicked the ball |

> [!important]
> In English, **the subject normally controls subject-verb agreement**, not the object.

Example:

> The boy **plays** cricket.

> The boys **play** cricket.

The object `cricket` does not control the verb.

---

# 5. Direct Object

The **direct object** directly receives the action of the verb.

Example:

> Ravi kicked the ball.

Verb:

> kicked

Ask:

> Kicked what?

Answer:

> the ball

Therefore:

$$
\boxed{\text{Direct Object = the ball}}
$$

---

# 6. Direct Object Recognition

> [!tip]
> Find the action verb and ask:
>
> **Verb + what?**
>
> or
>
> **Verb + whom?**
>
> The answer is usually the direct object.

### Example

> She bought a laptop.

Ask:

> Bought what?

Answer:

> a laptop

Therefore:

$$
\boxed{\text{Direct Object = a laptop}}
$$

---

# 7. Examples of Direct Objects

| Sentence | Verb | Direct Object |
|---|---|---|
| I read a book. | read | a book |
| She opened the door. | opened | the door |
| They solved the problem. | solved | the problem |
| Ravi bought a phone. | bought | a phone |
| We watched a movie. | watched | a movie |

---

# 8. Indirect Object

An **indirect object** usually tells us **to whom**, **for whom**, or **for what person** something is done.

Example:

> Ravi gave me a book.

Here:

- Ravi = Subject
- gave = Verb
- me = Indirect Object
- a book = Direct Object

### Questions

Gave what?

> a book → Direct Object

Gave to whom?

> me → Indirect Object

---

# 9. Basic Indirect Object Structure

$$
\boxed{\text{Subject} + \text{Verb} + \text{Indirect Object} + \text{Direct Object}}
$$

Example:

> She gave her brother a gift.

$$
\boxed{\text{She} + \text{gave} + \text{her brother} + \text{a gift}}
$$

- Subject = She
- Verb = gave
- Indirect Object = her brother
- Direct Object = a gift

---

# 10. Direct vs Indirect Object

| Question | Object |
|---|---|
| Verb + what? | Direct Object |
| Verb + whom? | Direct Object |
| Verb + to whom? | Indirect Object |
| Verb + for whom? | Indirect Object |

Example:

> The teacher gave the student a book.

What did the teacher give?

> a book → Direct Object

To whom?

> the student → Indirect Object

---

# 11. Prepositional Form of Indirect Object

The indirect object can also appear after a preposition.

Example:

> She gave a book to Ravi.

Here:

- a book = Direct Object
- Ravi = Object of the preposition `to`

Compare:

> She gave Ravi a book.

and:

> She gave a book to Ravi.

Both express a similar meaning.

---

# 12. Object of a Preposition

A noun or pronoun following a preposition is called the **object of the preposition**.

Common prepositions:

- to
- for
- with
- from
- at
- in
- on
- by
- about
- between
- among
- under
- over

Example:

> She spoke to Ravi.

`to` = preposition

`Ravi` = object of the preposition

---

# 13. Object Types

There are three important object concepts for placement grammar:

1. Direct Object
2. Indirect Object
3. Object of a Preposition

### Example

> She gave Ravi a book on grammar.

- She → Subject
- gave → Verb
- Ravi → Indirect Object
- a book → Direct Object
- grammar → Object of the preposition `on`

---

# 14. Object vs Subject

Compare:

> Ravi helped Arun.

Subject:

> Ravi

Object:

> Arun

Now reverse the sentence:

> Arun helped Ravi.

Subject:

> Arun

Object:

> Ravi

> [!important]
> The same noun can be a **subject in one sentence** and an **object in another**.

Its grammatical role depends on its position and function.

---

# 15. Subject and Object Pronouns

Pronouns change form depending on whether they are subjects or objects.

| Subject Pronoun | Object Pronoun |
|---|---|
| I | me |
| we | us |
| you | you |
| he | him |
| she | her |
| it | it |
| they | them |
| who | whom |

### Examples

> **I** helped him.

> He helped **me**.

> **She** called them.

> They called **her**.

---

# 16. Subject Pronoun vs Object Pronoun

### Subject Position

> He called me.

`He` = Subject

`me` = Object

### Object Position

> The manager called him.

`him` = Object

Not:

> The manager called he.

> [!warning]
> `he`, `she`, `I`, `we`, and `they` are generally subject forms.
>
> `him`, `her`, `me`, `us`, and `them` are object forms.

---

# 17. The "Me vs I" Pattern

This is a common grammar question.

Incorrect:

> Ravi and me went to the office.

Correct:

> Ravi and I went to the office.

Why?

The pronouns are subjects.

Remove `Ravi and`:

> I went to the office.

Not:

> Me went to the office.

---

## Object Position

> The manager called Ravi and me.

Remove `Ravi and`:

> The manager called me.

Not:

> The manager called I.

### Quick Rule

> [!tip]
> If the pronoun **does the action** → `I`
>
> If the pronoun **receives the action** → `me`

---

# 18. The "He vs Him" Pattern

Subject:

> He helped me.

Object:

> I helped him.

### Test

Remove the other person.

> He helped me.

Correct.

> The manager helped him.

Correct.

> [!important]
> **He = subject**
>
> **Him = object**

---

# 19. The "She vs Her" Pattern

Subject:

> She called me.

Object:

> I called her.

Incorrect:

> Her called me.

Incorrect:

> I called she.

Correct:

> She called me.

> I called her.

---

# 20. The "They vs Them" Pattern

Subject:

> They invited us.

Object:

> We invited them.

### Quick Test

Ask:

> Who performed the action?

> They.

Ask:

> Whom did we invite?

> them.

---

# 21. Subject-Object Recognition

> [!important]
> Use this three-step method:
>
> **Step 1:** Find the main verb.
>
> **Step 2:** Ask **Who/What performs the action?** → Subject.
>
> **Step 3:** Ask **Whom/What receives the action?** → Object.

Example:

> The teacher praised the student.

Who praised?

> teacher → Subject

Praised whom?

> student → Object

---

# 22. Transitive Verb

A **transitive verb** normally takes an object.

Examples:

> She opened the door.

> He bought a car.

> Ravi solved the problem.

The verbs:

- opened
- bought
- solved

have objects.

### Formula

$$
\boxed{\text{Subject} + \text{Transitive Verb} + \text{Object}}
$$

---

# 23. Intransitive Verb

An **intransitive verb** does not normally take a direct object.

Examples:

> The baby slept.

> The sun rises.

> He laughed.

> They arrived.

You cannot normally ask:

> slept what?

> arrived what?

There is no direct object.

### Formula

$$
\boxed{\text{Subject} + \text{Intransitive Verb}}
$$

---

# 24. Transitive vs Intransitive

| Type | Object Required? | Example |
|---|---|---|
| Transitive | Yes | She opened the door. |
| Intransitive | No | She slept. |

### Recognition

> [!important]
> If the verb can naturally answer:
>
> **what? / whom?**
>
> it may be transitive.
>
> If no direct object is possible, it is generally intransitive.

---

Examples:

# 26. Common Intransitive Verbs

Examples:

- arrive
- sleep
- laugh
- cry
- happen
- occur
- die
- go
- come
- rise
- fall
- disappear

Examples:

> The train arrived.

> The baby slept.

> Some verbs can be transitive or intransitive depending on their usage.

Example:

> The door opened.

Intransitive.

> She opened the door.

---

# 27. Verbs That Can Be Both Transitive and Intransitive

### Open

> The door opened.

No direct object.

> She opened the door.

Direct object:

> the door

### Run

> He runs every morning.

No object.

> He runs a company.

Object:

> a company

### Change

> The weather changed.

No object.

> The company changed the policy.

Object:

> the policy

> [!important]
> Do not memorize every verb as permanently transitive or intransitive. Check how it is used in the sentence.

---

# 28. Object Complement

An **object complement** gives additional information about the object.

Example:

> They elected Ravi captain.

Here:

- They = Subject
- elected = Verb
- Ravi = Object
- captain = Object Complement

`captain` describes or renames `Ravi`.

### Pattern

$$
\boxed{S + V + O + Object\ Complement}
$$

---

# 29. More Object Complement Examples

> They painted the wall red.

Object:

> the wall

Object Complement:

> red

---

> The committee named him chairman.

Object:

> him

Object Complement:

> chairman

---

> We found the movie boring.

Object:

> the movie

Object Complement:

> boring

---

# 30. Subject Complement

A **subject complement** gives information about the subject, usually after a linking verb.

Example:

> Ravi is a doctor.

Subject:

> Ravi

Linking verb:

> is

Subject Complement:

> a doctor

It describes or identifies Ravi.

### Formula

$$
\boxed{S + Linking\ Verb + Subject\ Complement}
$$

---

# 31. Subject Complement vs Object

Compare:

> Ravi is a doctor.

`a doctor` = Subject Complement

It describes Ravi.

Now:

> Ravi helped the doctor.

`the doctor` = Object

The doctor receives the action.

> [!important]
> A complement **describes or identifies**.
>
> An object **receives an action**.

---

# 32. Linking Verbs

Common linking verbs:

- be
- seem
- become
- appear
- feel
- look
- sound
- smell
- taste
- remain
- stay
- grow

Examples:

> She is happy.

> He became a doctor.

> The food smells delicious.

> The idea sounds interesting.

These usually connect the subject to a complement rather than taking a direct object.

---

# 33. Object vs Complement

### Object

Receives action.

> She opened the door.

`door` receives the action.

### Complement

Describes/identifies.

> She is a doctor.

`doctor` identifies the subject.

---

# 34. Direct Object + Indirect Object Pattern

### Pattern

$$
\boxed{S + V + IO + DO}
$$

Example:

> The teacher gave the students homework.

- The teacher = Subject
- gave = Verb
- the students = Indirect Object
- homework = Direct Object

### Recognition

Ask:

> Gave what?

> homework → Direct Object

> Gave to whom?

> students → Indirect Object

---

# 35. Double Object Construction

Some verbs commonly take two objects.

Examples:

- give
- send
- tell
- show
- offer
- lend
- buy
- teach
- bring

Example:

> She sent me an email.

- me = Indirect Object
- an email = Direct Object

---

# 36. Two Ways to Express Indirect Objects

### Form 1

$$
\boxed{S + V + IO + DO}
$$

> She gave me a book.

### Form 2

$$
\boxed{S + V + DO + to/for + IO}
$$

> She gave a book to me.

Both can express similar relationships.

---

# 37. To vs For

Some verbs commonly use `to`:

- give
- send
- show
- tell
- lend
- offer

Example:

> She gave a book to Ravi.

Some actions commonly use `for`:

- buy
- make
- cook
- get
- find

Example:

> She bought a gift for Ravi.

> [!tip]
> Do not mechanically replace `to` and `for`. Learn the natural verb pattern.

---

# 38. Object After Preposition

Examples:

> I spoke to him.

> She worked with me.

> They came from Chennai.

> He sat beside her.

The pronouns:

- him
- me
- Chennai
- her

are objects of prepositions.

### Pronoun Rule

After a preposition, use an object pronoun.

Correct:

> between you and me

Incorrect:

> between you and I

---

# 39. "Between You and Me"

This is a common placement grammar trap.

Correct:

> This is between you and me.

Why?

`between` is a preposition.

Therefore:

> you = object form unchanged

> me = object form

Incorrect:

> between you and I

---

# 40. Subject vs Object in Questions

### Question

> Who called you?

Subject:

> Who

Object:

> you

### Question

> Whom did you call?

Subject:

> you

Object:

> whom

### Key Difference

> [!important]
> **Who → Subject**
>
> **Whom → Object**

---

# 41. Who vs Whom — Fast Test

Replace with:

### He/She/They

If `he/she/they` works:

> Who

### Him/Her/Them

If `him/her/them` works:

> Whom

Example:

> ___ called you?

`He called you.`

Therefore:

> Who called you?

Example:

> You called ___?

`You called him.`

Therefore:

> Whom did you call?

---

# 42. Modern Usage of "Whom"

In everyday English, `who` is often used where traditional grammar would use `whom`.

However, in grammar tests, formal written questions may distinguish them.

> [!important]
> For placement exams, learn the traditional distinction:
>
> **Who = Subject**
>
> **Whom = Object**

---

# 43. Object in Passive Voice

This is an important connection with [[Active and Passive Voice]].

### Active

> Ravi kicked the ball.

Subject:

> Ravi

Object:

> the ball

### Passive

> The ball was kicked by Ravi.

The original object becomes the grammatical subject of the passive sentence.

### Transformation

$$
\boxed{\text{Active Object} \rightarrow \text{Passive Subject}}
$$

---

# 44. Subject-Object Transformation

### Active

> The manager approved the proposal.

Subject:

> manager

Object:

> proposal

### Passive

> The proposal was approved by the manager.

Now:

> proposal = grammatical subject

> manager = object of `by`

> [!important]
> This is why identifying subject and object is essential for Active/Passive Voice questions.

# 46. Pronoun Case Recognition

> [!important]
> If the pronoun **performs the action**, use the subject form.
>
> If the pronoun **receives the action or follows a preposition**, use the object form.

Examples:

> **I** called him.

> She called **me**.

> **They** helped us.

> We helped **them**.

> This is for **her**.

---

# 47. Subject-Verb Agreement and Objects

This is a major error-detection trap.

Example:

> The list of candidates **is** ready.

Subject:

> list

Object-like noun:

> candidates

The verb agrees with `list`.

Another:

> The students in the classroom **are** studying.

Subject:

> students

`classroom` is inside a prepositional phrase.

> [!tip]
> Never choose the verb based only on the nearest noun.

# 48. Pattern Recognition

## Pattern 1 — Subject

### How to Recognize

Ask:

> Who/What performs the action?

Example:

> Ravi solved the problem.

Answer:

> Ravi

$$
\boxed{\text{Subject = Ravi}}
$$

---

## Pattern 2 — Direct Object

### How to Recognize

Ask:

> Verb + what/whom?

Example:

> Ravi solved the problem.

Solved what?

> the problem

$$
\boxed{\text{Direct Object = the problem}}
$$

---

## Pattern 3 — Indirect Object

### How to Recognize

Ask:

> To whom?

or:

> For whom?

Example:

> Ravi gave me a book.

Gave to whom?

> me

$$
\boxed{\text{Indirect Object = me}}
$$

---

## Pattern 4 — Object of Preposition

### How to Recognize

Find a preposition and ask:

> What/whom comes after it?

Example:

> She spoke to Ravi.

`to` → preposition

`Ravi` → object of preposition

---

## Pattern 5 — Transitive Verb

### How to Recognize

If the verb takes a direct object:

> She opened the door.

Think:

$$
\boxed{Transitive}
$$

---

## Pattern 6 — Intransitive Verb

### How to Recognize

If there is no direct object:

> The baby slept.

Think:

$$
\boxed{Intransitive}
$$

---

## Pattern 7 — Subject Pronoun

### How to Recognize

Pronoun performs the action.

Use:

> I, we, he, she, they

Example:

> She called him.

---

## Pattern 8 — Object Pronoun

### How to Recognize

Pronoun receives action or follows a preposition.

Use:

> me, us, him, her, them

Example:

> She called him.

---

## Pattern 9 — Who vs Whom

### How to Recognize

Subject:

> Who called?

Object:

> Whom did you call?

---

## Pattern 10 — Active to Passive

### How to Recognize

Find:

> Subject + Verb + Object

The object can become the passive subject.

Example:

> Ravi solved the problem.

↓

> The problem was solved by Ravi.

Therefore the verb takes an object.

### Answer

$$
\boxed{\text{Transitive}}
$$

# 54. Common Mistakes

> [!warning] Avoid These

### Mistake 1 — Confusing Subject and Object

> Ravi helped Arun.

Ravi = Subject.

Arun = Object.

Do not choose the second noun automatically as the subject.

---

### Mistake 2 — Choosing the Nearest Noun

> The list of students is ready.

Subject:

> list

Not:

> students

---

### Mistake 3 — Using Subject Pronoun as Object

Incorrect:

> She called I.

Correct:

> She called me.

---

### Mistake 4 — Using Object Pronoun as Subject

Incorrect:

> Me went to college.

Correct:

> I went to college.

---

### Mistake 5 — Using "I" After a Preposition

Incorrect:

> between you and I

Correct:

> between you and me

---

### Mistake 6 — Confusing Direct and Indirect Object

> She gave Ravi a book.

`Ravi` = Indirect Object.

`a book` = Direct Object.

Ask:

> gave what? → book

> gave to whom? → Ravi

---

### Mistake 7 — Assuming Every Verb Has an Object

> The baby slept.

No direct object.

---

### Mistake 8 — Confusing Complement with Object

> Ravi is a doctor.

`doctor` is a subject complement.

It does not receive an action.

---

### Mistake 9 — Misusing Who and Whom

> Who called you?

Subject.

> Whom did you call?

Object.

---

### Mistake 10 — Ignoring Passive Voice

> The ball was kicked by Ravi.

The grammatical subject is:

> the ball

Although Ravi performs the original action.

---

# 55. Shortcuts

> [!tip]
> **Shortcut 1 — Subject Test**
>
> Ask:
>
> **Who/What performs the action?**
>
> Answer = Subject.

---

> [!tip]
> **Shortcut 2 — Direct Object Test**
>
> Ask:
>
> **Verb + what/whom?**
>
> Answer = Direct Object.

---

> [!tip]
> **Shortcut 3 — Indirect Object Test**
>
> Ask:
>
> **To whom? / For whom?**
>
> Answer = Indirect Object.

---

> [!tip]
> **Shortcut 4 — Pronoun Case Test**
>
> Replace the person with a single pronoun.
>
> If `he/she/they/I/we` works → Subject form.
>
> If `him/her/them/me/us` works → Object form.

---

> [!tip]
> **Shortcut 5 — Who/Whom**
>
> Try:
>
> `he/she/they` → Who
>
> `him/her/them` → Whom

---

> [!tip]
> **Shortcut 6 — Agreement**
>
> Ignore nouns inside:
>
> `of`
>
> `along with`
>
> `as well as`
>
> `together with`
>
> and find the actual subject before selecting the verb.

# 58. Final Exam Strategy

When solving a Subject-Object question:

### Step 1 — Find the Main Verb

Example:

> The manager approved the proposal.

Verb:

> approved

### Step 2 — Find the Subject

Ask:

> Who approved?

Answer:

> manager

### Step 3 — Find the Direct Object

Ask:

> Approved what?

Answer:

> proposal

### Step 4 — Check for Indirect Object

Ask:

> To whom? / For whom?

If an answer exists, identify the indirect object.

### Step 5 — Check Prepositions

If a noun/pronoun follows:

> to, for, with, from, between, etc.

check whether it is an object of the preposition.

### Step 6 — Check Pronoun Case

Subject:

> I, he, she, we, they

Object:

> me, him, her, us, them

### Step 7 — For Error Detection

Always identify the **true subject** before checking subject-verb agreement.

> [!important]
> The fastest method:
>
> **FIND VERB → FIND WHO/WHAT → SUBJECT → ASK WHAT/WHOM → OBJECT → CHECK PRONOUN CASE**

# 59. Golden Memory Trick

**Subject does the action, Direct Object receives it, and Indirect Object tells to whom or for whom it is done.**

## One-Line Recognition

**Find the verb, ask "Who/What?" for the subject, then ask "Verb + What/Whom?" for the direct object and "To/For Whom?" for the indirect object.**
